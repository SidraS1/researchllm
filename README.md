🧠 ReSearch AI – Intelligent RAG Paper Understanding Dashboard

ReSearch AI is an interactive Retrieval-Augmented Generation (RAG) platform designed to help researchers analyze academic papers efficiently. Users can upload research PDFs, automatically extract text, generate semantic chunks, perform intelligent question answering, create concise summaries, identify research gaps, and evaluate research quality using Google's Gemini AI.

🚀 Features

- 📄 Upload and parse academic PDF papers
- 🧩 Automatic text chunking with configurable chunk size and overlap
- 🔍 Retrieval-Augmented Generation (RAG) pipeline
- 🤖 Gemini AI-powered question answering
- 📝 Automatic research paper summarization
- 💡 Research gap identification
- ⚖️ Ablation analysis workspace
- 📊 G-Eval quality assessment
- 🗂️ Interactive vector index visualization
- 📈 Document statistics dashboard
- 🎨 Modern glassmorphism UI built with Tailwind CSS
- ⚡ Fully client-side processing for uploaded PDFs

⚙️ How It Works

1. Upload an academic PDF.
2. Extract text using PDF.js.
3. Split the document into semantic chunks.
4. Build an in-memory vector index.
5. Retrieve the most relevant chunks based on user queries.
6. Send retrieved context to Gemini AI.
7. Generate accurate, context-aware responses.
